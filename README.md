# Telegram Business + Gemini автоответчик

Асинхронный пример Telegram-бота на **aiogram 3.x**, который подключается к личному аккаунту через Telegram Business, хранит получаемые сообщения в SQLite и использует Gemini для анализа стиля и автоответов.

> Telegram Bot API не предоставляет боту историю переписки до его подключения. Этот бот начинает кэшировать доступные `business_message`-обновления только после подключения и запуска. Старые сообщения команда `.save` восстановить не может.

## Возможности

- Слушает только `business_message` и сохраняет входящие и исходящие сообщения бизнес-диалогов в SQLite.
- Владелец управляет ботом в нужном бизнес-чате командами `.save N`, `.ai on`, `.ai off`. Команды удаляются через `business_connection_id`, если у бота есть соответствующее право.
- `.save N` экспортирует последние N сохранённых сообщений в UTF-8 `.txt`, отправляет документ владельцу в личный чат с ботом и просит Gemini создать профиль стиля. Профиль хранится отдельно для каждого бизнес-чата.
- При включённом автоответчике отвечает на новые входящие сообщения с контекстом последних 12 сообщений и сохранённым профилем. Во время генерации обновляет индикатор «печатает…».
- Ошибки и сообщения о состоянии отправляются в личный чат владельца, а не собеседнику.

## Установка и запуск

Нужен Python **3.10–3.14** (рекомендуется 3.11–3.14). Python 3.15 пока не поддерживается зависимостями проекта: `pip` сообщит `Requires-Python ... <3.15` и не найдёт подходящую версию aiogram.

Сначала проверьте версию:

```powershell
python --version
py -0p
```

Если у вас Python 3.15, установите Python 3.14 или 3.13 и создайте окружение именно этой версией (Windows PowerShell):

```powershell
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Linux/macOS:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен от `@BotFather`.
- `GEMINI_API_KEY` — ключ Google Gemini API из Google AI Studio.
- `OWNER_ID` — числовой Telegram ID владельца аккаунта (не username).
- `GEMINI_MODEL` — по умолчанию `gemini-3.5-flash-lite`.

Затем запустите:

```bash
python bot.py
```

SQLite-файл и экспортные файлы появятся в `data/`. Папка исключена из Git, так как в ней могут быть личные переписки.

## Настройка Telegram Business

1. Создайте бота через `@BotFather` (`/newbot`) и скопируйте токен в `.env`.
2. В настройках бота через `@BotFather` откройте **Bot Settings → Business Mode** и включите режим Business. Если пункт недоступен, проверьте актуальные требования Telegram/доступность функции для аккаунта.
3. В Telegram откройте **Настройки → Telegram для бизнеса → Чат-боты**, выберите созданного бота и подключите его к аккаунту.
4. Разрешите боту доступ к тем личным чатам, которые он должен обрабатывать, и разрешите отправку/удаление сообщений, если эти настройки доступны в клиенте. Боту нужны права на удаление для удаления `.save`/`.ai` команд.
5. Откройте личный чат с ботом и нажмите **Start** (`/start`). Это обязательно: Telegram не позволяет боту первым начать личный диалог. Здесь бот будет присылать владельцу экспорт и уведомления.
6. Запустите `bot.py`, затем общайтесь в выбранных бизнес-чатах. Кэширование начинается с этого момента.

Polling запрашивает только `business_message` и `business_connection`; обычные сообщения вне бизнес-контекста бот не обрабатывает.

## Команды в бизнес-чате

Отправлять команды должен именно владелец аккаунта, с Telegram ID, указанным в `OWNER_ID`:

```text
.save 100
.ai on
.ai off
```

`.save N` включает анализ стиля для этого диалога независимо от состояния автоответчика. Перед `.ai on` выполните хотя бы одну команду `.save N`, чтобы создать профиль стиля. Режим автоответчика хранится отдельно для каждого сочетания бизнес-подключения и чата.

## Ограничения и безопасность

- Бот не может читать переписку, которая была до его подключения; в SQLite попадают только обновления, доставленные Telegram после запуска/подключения.
- Чтобы получить экспорт в личный чат, владелец должен предварительно открыть чат с ботом и нажать Start. Бот не может отправлять файлы непосредственно в Saved Messages владельца через Bot API; поэтому документ доставляется в личный диалог с ботом.
- Доступность отправки от имени аккаунта, удаления и индикатора набора определяется правами бизнес-подключения и поддержкой метода Telegram Bot API. При отказе соответствующая ошибка попадёт в лог/личку владельца.
- Не публикуйте `.env`, SQLite-файл, экспорт переписок или API-ключи. Передача истории в Gemini означает передачу её содержимого стороннему API; используйте только с согласия и с учётом применимых правил конфиденциальности.
- Автоответчик может отправить недостоверный или неподходящий ответ. Включайте его только в чатах, где это допустимо, и контролируйте его работу.
