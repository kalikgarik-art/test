# Telegram Business мини-игры на виртуальный баланс

Учебный Telegram-бот на Python 3.10+, aiogram 3.x и асинхронном SQLite (`aiosqlite`). Он обрабатывает обычные сообщения боту и обновления Telegram Business `business_message`, отвечает в Business-чате с тем же `business_connection_id` и хранит общий профиль каждого пользователя.

> Баланс и ставки здесь **только виртуальные**: бот не принимает платежи, не поддерживает вывод или обмен на реальные деньги и не предназначен для игры на деньги.

## Возможности

- Начисление стартового баланса `1 000$` при первом сообщении.
- `.б`, `.баланс`, ежедневный бонус `.бонус` (100–500$ раз в 24 часа).
- Рулетка, кости, монетка, краш, слоты, больше/меньше и мины.
- Перевод виртуального баланса ответом на сообщение игрока в обычной группе.
- Админ-команды, доступные только ID из `OWNER_ID`.
- Все исходы игр получают случайность из модуля Python `secrets`; списание ставок, переводы и бонусы выполняются транзакционно.

## Установка и запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\\Scripts\\Activate.ps1

python -m pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и заполните `BOT_TOKEN` токеном от `@BotFather`, `OWNER_ID` своим **числовым** Telegram ID и при необходимости поменяйте `DATABASE_PATH`. Для первого запуска можно оставить `OWNER_ID` пустым, написать боту `.ид`, вписать полученный ID в `.env` и перезапустить бота. Без `OWNER_ID` команды выдачи/снятия отключены.

```bash
python main.py
```

SQLite-файл и каталог `data/` создаются автоматически. Бот работает через long polling: процесс `python main.py` должен оставаться запущенным.

## Настройка Telegram Business

1. В `@BotFather` создайте бота через `/newbot` (если ещё не создан) и включите Business Mode: `/mybots` → выберите бота → **Bot Settings** → **Business Mode** → включить. Названия пунктов могут немного отличаться в версиях Telegram.
2. В аккаунте владельца откройте **Настройки → Telegram для бизнеса → Чат-боты** (Settings → Telegram Business → Chatbots), добавьте созданного бота и выберите, к каким личным чатам ему разрешён доступ.
3. Разрешите боту отвечать на сообщения в выбранных чатах. Запустите `python main.py`, затем проверьте команду `.б` в чате, который разрешили боту.

Бот может отвечать от имени бизнес-аккаунта только в рамках выданных Telegram разрешений и доступных чатов. Business-сообщения обрабатываются как личные чаты; в обычном режиме бот также отвечает в личном чате с самим ботом.

## Команды

Все игровые команды начинаются с точки; регистр не важен. Сумма ставки/перевода/админ-операции может быть целым числом или иметь до двух знаков после точки/запятой.

| Команда | Формат и правила |
|---|---|
| Баланс | `.б` или `.баланс` |
| Бонус | `.бонус` — 100–500$ раз в 24 часа |
| Рулетка | `.рулетка <ставка> <выбор>` или `.р <ставка> <выбор>`; красное/чёрное, чёт/нечёт — x2; зелёное — x14; точное число — x36 |
| Кости | `.кости <ставка> <1–6>` — x5; `.куб <ставка> <чет/нечет>` — x1.9 |
| Монетка | `.монетка <ставка> <орел/решка>` или сокращения `о`/`р` — x1.95 |
| Краш | `.краш <ставка> <автовывод>` — например, `.краш 100 1.50`; выигрыш, когда краш не ниже выбранного коэффициента |
| Слоты | `.слоты <ставка>` или `.с <ставка>`; две одинаковые — x1.5, три фрукта — x5, три 💎 — x15, три 7️⃣ — x50 |
| Больше/меньше | `.бм <ставка> <б/м>` — число 1–100, 50 проигрывает, угаданная сторона — x1.95 |
| Мины | `.мины <ставка> <ячейка 1–9>` — поле 3×3, три мины, безопасная клетка — x1.4 |
| Перевод | Ответьте `.передать <сумма>` на сообщение игрока; удобнее всего использовать в общей группе с ботом |
| Выдать | Владелец отвечает `.выдать <сумма>` на сообщение игрока |
| Снять | Владелец: `.снять <сумма>` снимает с собственного баланса; ответ на сообщение игрока снимает у него |
| Справка / ID | `.помощь`, `.ид` |

В рулетке `0` или `з` означает зелёный сектор с выплатой x14. Чтобы поставить именно на число 0 с выплатой x36, используйте `#0`, например `.р 10 #0`.

Чтобы переводы ответом работали в группе, добавьте туда обычного бота. При включённом Privacy Mode бот может не получать текстовые сообщения, начинающиеся с точки: если это случилось, в `@BotFather` выполните `/setprivacy` → выберите бота → **Disable** и добавьте бота в группу снова. Для личных чатов и Telegram Business это менять не требуется.
